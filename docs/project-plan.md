# 更好的攻略制作器（Better Walkthrough Maker）项目规划

> 状态：已与需求方逐轮确认（设计树走完，本版为终版规划）。
> 日期：2026-xx-xx（首次定稿）

## 1. 产品定位

- **一句话**：面向游戏攻略作者的桌面设计工具，用"模板 + 自由画布"的方式制作攻略配图，导出 PNG 发布到小黑盒等平台。
- **目标用户**：作者本人自用起步，架构上预留开放给其他攻略作者的余地。
- **平台**：Windows 桌面优先（基于 Qt 6，具备跨平台潜力）。
- **核心范式**：混合模式——模板提供初始布局，之后可自由拖拽编辑（Canva 式）。

## 2. 命名与标识

| 项 | 值 |
|---|---|
| 中文名 | 更好的攻略制作器 |
| 英文名 | Better Walkthrough Maker（工作目录 Better-Walkthrough-Maker） |
| 项目扩展名 | `.bwm`（Better Walkthrough Maker） |

## 3. 核心概念（领域词汇表）

| 概念 | 定义 |
|---|---|
| 项目 | 对应一个游戏，磁盘上是一个 `.bwm` 文件夹，自包含 |
| 攻略 | 项目下的一个攻略（如"出血流装备推荐"），绑定一个模板类型 |
| 页面 | 攻略下的一页，一页 = 一张导出的 PNG |
| 组件 | 画布上的元素：图片 / 文本 / 表格 / 形状 / 贴纸 / 背景 |
| 模板 | 页面布局 + 样式的蓝图，按攻略类型分类 |
| 主题包 | 配色 + 字体 + 组件默认样式（美化包的一部分） |
| 素材包 | 装饰素材合集：边框、标题装饰、贴纸、图标（美化包的一部分） |
| 素材库 | 项目内已导入的图片资源（原图复制进项目） |

## 4. 数据模型

### 4.1 项目文件夹结构

```
我的项目名.bwm/
├── project.json          # 项目元信息 + 攻略/页面/组件数据
├── assets/               # 素材原图（导入时复制进项目）
│   └── <素材ID>.png
├── templates/            # 项目内自定义模板（可选）
└── themes/               # 项目内自定义主题（可选）
```

`project.json` 设计要点：

- 纯 JSON，可读、可版本化；文件头带 `formatVersion` 字段，为格式迁移预留。
- 结构：`项目 → 攻略[] → 页面[] → 组件[]`。
- 组件统一基类字段：`id`、`类型`、`位置(x,y)`、`尺寸(w,h)`、`旋转`、`zOrder`、`可见性`、`锁定`。

### 4.2 组件数据要点

| 组件 | 专属字段 |
|---|---|
| 图片 | 素材引用、裁剪矩形、圆角半径、描边（后期：蒙版、滤镜） |
| 文本 | 内容、富文本样式（字体/字号/颜色/粗斜体/对齐/行距/阴影） |
| 表格 | 行×列、单元格文本、样式（表头/边框/斑马纹/列宽） |
| 形状 | 类型（矩形/圆角矩形/椭圆/线条/箭头）、填充、描边 |
| 贴纸 | 素材包资源引用、缩放 |
| 背景 | 纯色 / 渐变 / 图片（页面级属性） |

## 5. 功能模块

### 5.1 项目管理

- 新建项目向导：游戏名、图标、默认画布尺寸、默认主题。
- 打开 / 最近项目列表。
- 项目自包含（素材复制进 `assets/`），整个文件夹可备份、迁移、分发。
- 自动保存 + 崩溃恢复：定时写 `project.json` 快照，重启时提示恢复。

### 5.2 编辑器（画布）

- 画布：缩放（10%–400%）、平移、标尺、参考线、网格吸附。
- 组件操作：拖拽移动、8 手柄缩放、旋转、对齐（左/中/右/顶/底/等距分布）、图层管理（上移/下移/置顶/置底 + 图层面板）、多选、编组、复制克隆（支持跨页面）。
- 撤销 / 重做：命令模式，内存内不限步数。
- 快捷键：Ctrl+C/V/Z/Y、Delete、方向键微调、对齐快捷键。

### 5.3 组件系统

- **图片**：裁剪（自由 / 固定比例预设 16:9、4:3、1:1）、圆角、描边；蒙版、滤镜列入后期。
- **文本**：富文本编辑（内嵌编辑器），中文字体支持。
- **表格**：单元格内编辑、行列增删、**CSV 粘贴导入**、样式（表头/边框/斑马纹/对齐）、列宽拖拽。
- **形状**：矩形 / 圆角矩形 / 椭圆 / 线条 / 箭头 / 分割线。
- **贴纸**：从素材包拖入画布。
- **背景**：纯色 / 渐变 / 图片（页面级）。

### 5.4 素材库

- 面板：缩略图网格、批量导入（多选文件 / 拖拽）、重命名、删除（删除前检查引用）。
- 性能：原图按需加载，画布与面板使用缩略图缓存。

### 5.5 模板系统

- **内置六类模板**（第一版全做）：
  1. 装备推荐（卡片网格：装备图 + 名称 + 获取途径 + 推荐度）
  2. 属性 / 数值对比（表格为主：属性面板、武器对比）
  3. 剧情流程（时间线 / 步骤条：章节 → 关键节点 → 分支选项）
  4. 武器 / 角色评测（大图 + 评分条 + 优缺点列表）
  5. 地图 / 点位（背景图 + 标注点）
  6. 通用封面（标题 + 副标题 + 配图 + 作者署名位）
- 新建攻略时选择模板 → 生成初始页面，之后自由编辑。
- "保存为模板"：把做好的攻略 / 页面存为新模板，按类型分类。
- 模板导入 / 导出（`.json`），可分享给他人。
- 后期能力：模板占位符 / 变量（标记可替换区域）。

### 5.6 美化包

- **主题包**：配色（主色/辅色/背景/文字）、字体（标题/正文）、组件默认样式；应用粒度为项目级。
- **素材包**：标题装饰线、角标、推荐度星标、箭头、分割线、卡片边框等装饰素材，拖入画布即用；支持导入 / 导出分享。
- 与模板**解耦**：模板管布局，美化包管外观，自由组合。
- 第一版内置：深色游戏风 + 浅色简洁风两套主题 + 一套基础素材包。

### 5.7 导出

- 形态：单页 PNG / 当前攻略全部页（批量）/ 长图（页面纵向拼接，无缝或带分隔线选项）。
- 分辨率倍率：1x / 2x / 3x（**默认 2x**——小黑盒会压缩图片，宁大勿小）。
- 剪贴板复制：复制当前页 / 全部页到剪贴板，直接粘贴进小黑盒编辑器（不做一键发布，小黑盒无公开 API，浏览器自动化脆弱易失效）。
- 尺寸预设：小黑盒（规格待实测后填入）+ 自定义（保存常用尺寸）。
- 命名规则：`攻略名_01.png`，导出到指定文件夹，带导出进度。

### 5.8 全局设置

- 作者署名（如小黑盒 ID）：全局设置项，导出时可选择应用。
- 默认画布尺寸、默认主题、默认字体。
- 自动保存间隔、最近项目数量。
- 界面语言（中文默认）、界面深浅色主题。

## 6. 技术架构

- **技术栈**：Qt 6（Widgets 模块）+ CMake + C++20。
- **画布**：`QGraphicsScene/View` + 自定义 `QGraphicsItem`（各组件）。
- **导出渲染**：`QPainter` 离屏渲染同一场景，所见即所得，支持倍率输出 PNG。
- **富文本**：`QTextDocument`。
- **序列化**：`QJsonDocument`。

### 6.1 模块分层

```
src/
  app/        # 入口、主窗口、应用装配
  core/       # 数据模型、序列化（project.json）
  editor/     # 画布场景、组件 item、命令（撤销重做）
  project/    # 项目管理、素材库、自动保存
  template/   # 模板解析、模板库
  theme/      # 主题包、素材包
  export/     # 导出、长图拼接、剪贴板
  settings/   # 全局设置
tests/        # 镜像 src/，见第 8 节
docs/         # 文档（本文件）
```

## 8. 测试策略（遵循 AGENTS.md）

- 测试放 `tests/`，目录结构镜像 `src/`，命名 `test_<单元>_<行为>`。
- 重点覆盖：
  - 数据模型与 `project.json` 序列化（含版本迁移、损坏文件处理）
  - CSV 解析（含中文、引号、空值、错误路径）
  - 导出渲染（组件 → PNG 像素级抽查、倍率、长图拼接、超限分片）
  - 模板解析（内置六类模板的结构完整性）
- 提交使用 Conventional Commits，中文信息。

## 9. 风险与对策

| 风险 | 对策 |
|---|---|
| 小黑盒图片规格未核实（单张上限/张数/推荐尺寸） | 导出默认 2x 宁大勿小；尺寸预设可自定义；软件可用后实测上传验证 |
| Qt 学习成本（若未使用过 Qt） | M1 先做画布小原型验证技术路线再全面铺开 |
| 大图性能（4K 游戏截图） | 缩略图缓存、按需加载、原图延迟解码 |
| 范围膨胀 | 严格按里程碑推进，M4 前不碰模板与美化 |
| 长图高度超过 QImage 限制（约 32767px） | 导出长图前检测，超限时自动分片并提示 |
| 模板/主题格式变更破坏旧项目 | `formatVersion` + 迁移函数，测试覆盖 |

## 10. 明确不做（本期范围外）

- 一键发布到小黑盒（无公开 API）。
- 云同步 / 多设备（数据格式预留迁移性）。
- 蒙版、滤镜、GIF 导出（后期迭代）。
- 模板占位符 / 变量（后期迭代）。
- 移动端版本。
