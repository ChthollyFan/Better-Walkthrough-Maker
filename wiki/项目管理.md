# 项目管理

## 1. 项目文件夹结构

一个「项目」= 一个游戏，对应磁盘上的一个 `.bwm` 文件夹：

```
我的项目.bwm/
├── project.json     # 唯一数据文件：项目名 + 攻略 / 页面 / 组件 / 文章
├── assets/          # 素材原图（导入时复制进项目，UUID 命名）
└── templates/       # 项目内自定义模板（保存模板时才创建）
```

要点：

- **自包含**：素材复制进 `assets/`，整个文件夹可备份、迁移、分发
- `assets/` 缺失时打开项目会自动补建
- 项目级 `themes/` 目录**尚未实现**，主题设置保存在全局设置里（见 [设置与快捷键](设置与快捷键.md)）
- ⚠️ **图片组件目前保存的是素材绝对路径**，而页面背景图、卡片边框图保存的是项目内相对路径。
  因此**整个项目文件夹改名或移动后，已插入的图片组件可能找不到文件，需要重新插入**。

数据文件的完整字段见 [数据格式](数据格式.md)。

## 2. 新建项目

**文件 → 新建项目…**（`Ctrl+N`）

1. 填写 `游戏名`（不能为空），选择 `默认画布尺寸`（竖图 1080×1440 / 横图 1920×1080 /
   方形 1080×1080 / 长图 1080×2400）
2. 点「创建」后再选择保存位置，程序在该位置创建 `<游戏名>.bwm` 文件夹
3. 若同名文件夹已存在会提示「项目已存在：<路径>」

创建后会初始化一个攻略「攻略 1」（类型 `cover`）与一页「页面 1」（尺寸取对话框所选），
并自动选中该页。

## 3. 打开项目与最近项目

- **文件 → 打开项目…**（`Ctrl+O`），文件过滤器为 `攻略项目 (project.json)`
- **文件 → 最近项目**：最多 10 条，条目是 `project.json` 的完整路径，最新在最上面；
  没有记录时显示不可点的「（无）」
- 打开成功后自动记录到最近项目、自动选中第一个攻略的第一页，并在状态栏提示 `已打开项目：<目录>`

程序**没有**「清除最近项目」功能；记录的文件被删除后点击该条目会弹出打开失败提示。

## 4. 项目结构面板

树的层级与显示文本：

| 层级 | 显示 | 说明 |
| --- | --- | --- |
| 项目根 | 游戏名 | — |
| 攻略 | `攻略 1（cover）` | 括号里是攻略类型的英文标识 |
| 页面 | `页面 1` | 一页 = 一张导出的 PNG |
| 文章 | `标题（文章）` | 同一攻略下，页面在前、文章在后 |

> 双击节点**没有**任何行为；节点也不能拖动排序、不能就地重命名——重命名一律走输入对话框。

### 右键菜单（按节点类型不同）

| 节点 | 菜单项 |
| --- | --- |
| 项目根 | `新建攻略…` |
| 攻略 | `新建页面…`、`从图片新建页面…`、`新建文章…`、`从文件导入文章…`、`重命名攻略…`、`删除攻略…` |
| 页面 | `重命名页面…`、`删除页面…`、`设置背景图…`、`清除背景图` |
| 文章 | `重命名文章…`、`删除文章…` |

### 新建攻略

弹出「新建攻略 - 选择模板」对话框，列出全部模板（条目格式 `<模板名>（N 页）`），
最后一项固定是 **`空白模板（1 页）`**，默认选中第一行。

- 从模板创建：复制模板的全部页面，并为每个组件重新生成 ID
- 空白模板：新建一个 `cover` 类型攻略 + 一页（尺寸取全局默认画布尺寸）
- 攻略标题自动为 `攻略 N`

内置六类模板的内容见 [模板与美化](模板与美化.md)。

### 新建页面

需先选中一个攻略（否则提示「请先选中一个攻略」）。页面尺寸四选一：
`竖图 1080×1440（推荐）`、`横图 1920×1080`、`方形 1080×1080`、`长图 1080×2400`；
默认选中该攻略已有第一页的尺寸，没有则用全局默认尺寸。页面名自动为 `页面 N`。

### 从图片新建页面

以图片原始像素尺寸建页，并把该图片复制进 `assets/` 后设为这一页的**整页背景图**。
图片单边超过 **16384px** 时会先等比缩小（与数据文件的尺寸防线一致）。

### 设置 / 清除背景图

- **设置背景图…**：选图（复制进 `assets/`）。若图片尺寸与页面尺寸不同，会询问
  「是否把页面尺寸调整为图片尺寸？」，默认选「是」；选「否」则保持页面尺寸，
  背景图等比裁剪铺满整页。
- 背景图的绘制规则是**等比覆盖、居中裁剪**（cover）：既不留白也不变形。
- **清除背景图**：仅清除引用，素材文件仍保留在素材库中，可在素材面板删除。

### 重命名

统一弹「新名称」输入框。取消、留空、或与原名相同都**不做任何修改**。

### 删除

除项目根（提示「项目节点不可删除」）外，删除都有确认框（默认「否」）：

- 页面：`确定删除页面「X」？`
- 攻略：`确定删除攻略「X」及其全部页面？`（连带该攻略下全部页面**与文章**）
- 文章：`确定删除文章「X」？`

> ⚠️ 删除**不可撤销**。删除页面后，文章里已有的 `![[W:P]]` 引用**不会**自动修正或提示，
> 索引前移后可能指向别的页面。

## 5. 保存、自动保存与崩溃恢复

### 手动保存

**文件 → 保存**（`Ctrl+S`）：先把画布上的编辑同步回数据模型，再用
`QSaveFile`（先写临时文件再原子替换）写入 `project.json`，成功后状态栏提示 `已保存`。

### 自动保存

- 默认**开启**（`文件 → 自动保存` 可切换；该开关状态不持久化，每次启动都是开启）
- 间隔默认 **5 分钟**，可在 **设置** 中改为 1–60 分钟（改动只在当前会话生效，重启后会回到 5 分钟）
- 只有项目存在且内容有改动时才写盘
- 结果通过状态栏提示：成功 `已自动保存`，失败显示错误信息

### 崩溃恢复

打开项目成功后会检查是否存在「上次中断的保存」，若存在则弹框：

> 检测到未完成的保存
> 上次保存可能被中断，是否恢复最近一次保存的内容？

默认选「是」；恢复成功后状态栏提示 `已从上次未完成的保存恢复`。

> ⚠️ **已知限制**：保存使用 `QSaveFile`，其临时文件名为 `project.json.<随机字符>`，
> 与恢复逻辑查找的 `project.json.tmp` 并不一致，因此**实际运行中该恢复提示通常不会触发**。
> 崩溃更可能留下 `project.json.<随机字符>` 残留文件（不影响下次打开，可手动删除），
> 请以定期 `Ctrl+S` 为准。详见 [常见问题](常见问题.md)。

### 未保存提示

只在**关闭窗口**时检查：`项目「X」有未保存的更改，是否保存？`，按钮为
`保存`（默认）/ `不保存` / `取消`；保存失败会取消关闭。

新建项目、打开其它项目、切换页面/文章都**不会**提示未保存——切换页面时画布内容已同步回
模型，因此不会丢数据。

## 6. 导出目录记忆

导出对话框会记住**上次使用的导出目录**（全局设置），下次打开自动填入。
