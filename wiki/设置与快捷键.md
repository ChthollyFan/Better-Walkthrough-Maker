# 设置与快捷键

## 1. 设置对话框

入口：**文件 → 设置…**（`Ctrl+,`）。只有点「确定」才会保存，保存后状态栏提示 `设置已保存`。

| 设置项 | 控件 | 范围 / 默认 |
| --- | --- | --- |
| 默认画布尺寸 | 下拉：竖图 1080×1440（默认）/ 横图 1920×1080 / 方形 1080×1080 / 长图 1080×2400 | 新建页面时的默认尺寸 |
| 自动保存间隔（分钟） | 数字框 | 1–60，默认 **5** |
| 作者署名 | 输入框 | 如作者昵称 / ID，用于导出署名 |

> ⚠️ 自动保存间隔有个已知问题：改动只在当前会话生效，**重启程序后会回到默认的 5 分钟**
> （启动时不会把该设置同步给项目管理器）。详见 [常见问题](常见问题.md)。

设置里**没有**的项（常见误解）：网格间距、默认缩放、语言切换、快捷键自定义、
导出倍率记忆、自动保存开关的持久化、清理最近项目。

## 2. 快捷键一览

### 文件与编辑

| 功能 | 快捷键 |
| --- | --- |
| 新建项目 | `Ctrl+N` |
| 打开项目 | `Ctrl+O` |
| 保存 | `Ctrl+S` |
| 导出 | `Ctrl+E` |
| 设置 | `Ctrl+,` |
| 退出 | 平台标准的退出键 |
| 撤销 / 重做 | `Ctrl+Z` / `Ctrl+Y` |
| 剪切 / 复制 / 粘贴 | `Ctrl+X` / `Ctrl+C` / `Ctrl+V` |
| 复制当前页到剪贴板 | `Ctrl+Shift+C` |
| 删除选中 | `Delete` |
| 全选 | `Ctrl+A` |

### 画布与预览

| 功能 | 快捷键 |
| --- | --- |
| 画布缩放（以鼠标为中心） | `Ctrl+滚轮` |
| 画布滚动 | 滚轮 |
| 文章预览缩放 | `Ctrl+滚轮` |

### 没有快捷键的操作

插入组件（图片 / 文本 / 表格 / 形状 / 装饰）、新建攻略 / 页面 / 文章、重命名与删除节点、
对齐与等距分布、吸附开关、方向键微调组件位置、适应窗口 / 100% 缩放等，目前都**没有**快捷键。

## 3. 设置存放位置

全局设置通过 Qt 的 `QSettings` 保存（Windows 下是注册表）：

```
HKEY_CURRENT_USER\Software\bwm\BetterWalkthroughMaker
```

| 键 | 含义 | 默认 |
| --- | --- | --- |
| `defaultPageSize` | 默认画布尺寸 | 1080×1440 |
| `autoSaveIntervalMs` | 自动保存间隔（毫秒，下限 1000） | 300000（5 分钟） |
| `authorName` | 作者署名 | 空 |
| `authorMark/position` | 署名水印位置 | `bottom-right` |
| `authorMark/fontFamily` | 署名字体 | 空（实际用 `Microsoft YaHei`） |
| `authorMark/fontSize` | 署名字号（6–400） | 18 |
| `authorMark/bold` | 署名加粗 | false |
| `authorMark/color` | 署名颜色（`#rrggbb`） | 黑色 |
| `authorMark/opacity` | 署名不透明度（0–100） | 63 |
| `recentProjects` | 最近项目列表（最多 10 条） | 空 |
| `theme` | 画布配色名 | `浅色页面` |
| `ui/style` | 界面外观（`dark` / `light` / `auto`） | `auto` |
| `windowGeometry` | 窗口位置与大小 | — |
| `lastExportDirectory` | 上次导出目录 | 空 |

> 项目数据（页面、组件、文章、模板）**不在注册表**里，全部在项目的
> `project.json` 与 `templates/` 中；项目**没有**自己的设置文件。

## 4. 窗口与文件

- 窗口位置 / 大小在关闭时保存，下次启动恢复
- 应用图标为内置的 `Chtholly.ico`；exe 文件图标由资源脚本嵌入
- 「帮助 → 关于」显示版本号（由 CMake 注入）、功能简介、MIT 许可与运行时 Qt 版本
