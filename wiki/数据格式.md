# 数据格式

本项目的数据只有两种文件：

| 文件 | 位置 | 说明 |
| --- | --- | --- |
| 项目数据 | `<项目目录>/project.json` | 项目名 + 攻略 / 页面 / 组件 / 文章 |
| 项目模板 | `<项目目录>/templates/<模板名>.json` | 从攻略保存的模板 |

两者都是 UTF-8、`QJsonDocument::Indented` 风格（4 空格缩进）、通过 `QSaveFile`
原子写入。当前 `formatVersion` 均为 **1**。

## 1. 领域层级

```
Project（一个游戏）
└── Walkthrough[]（攻略）
    ├── Page[]（页面，一页 = 一张导出 PNG）
    │   └── Component[]（组件：图片 / 文本 / 表格 / 形状 / 贴纸）
    └── Article[]（Markdown 文章，与页面同级）
```

## 2. project.json 顶层结构

| 键 | 类型 | 说明 |
| --- | --- | --- |
| `formatVersion` | int | 总是写出，当前为 `1` |
| `name` | string | 游戏名 / 项目名 |
| `walkthroughs` | array | 攻略列表（可为空数组） |
| `articles` | array | **旧格式遗留，只读不写**：反序列化时会被迁移进攻略 |

### walkthrough

| 键 | 类型 | 缺省回退 |
| --- | --- | --- |
| `title` | string | `未命名攻略` |
| `type` | string | 缺失或非字符串 → `cover`；未知字符串 → `custom` |
| `pages` | array | 空列表 |
| `articles` | array | 空列表 |

`type` 的取值：`equipment`、`stats_compare`、`story_flow`、`weapon_review`、
`map_points`、`cover`、`custom`。

### page

| 键 | 类型 | 说明 |
| --- | --- | --- |
| `name` | string | 缺失 → `未命名页面` |
| `width` / `height` | int | 逻辑像素；`≤0` / 非数字 / `>16384` → 回退 `1080×1440` |
| `backgroundImage` | string | **可选**，空则不写；项目内相对路径（如 `assets/xxx.png`） |
| `components` | array | 缺失 → 空列表 |

页面**没有**背景色字段：背景色由当前主题在渲染时提供。

### article

| 键 | 类型 | 说明 |
| --- | --- | --- |
| `id` | string | `QUuid`（无花括号） |
| `title` | string | 缺失 → `未命名文章` |
| `markdown` | string | 正文内嵌，支持 `![[W:P]]` 与 `![](assets/...)` |

### component（公共字段）

| 键 | 类型 | 默认 |
| --- | --- | --- |
| `id` | string | 空 |
| `type` | string | 缺失 → `shape`；未知值 → `shape` |
| `posX` / `posY` | double | 0 |
| `width` / `height` | double | 200 / 120 |
| `rotation` | double | 0（度） |
| `zOrder` | int | 0（大者在上层；导出按升序绘制） |
| `visible` | bool | true（`false` 的组件导出时跳过） |
| `locked` | bool | false |

除公共字段外，**恰好写一个**与 `type` 对应的嵌套对象：

| `type` | 嵌套键 | 专属字段 |
| --- | --- | --- |
| `image` | `image` | `assetId`（预留未使用）、`filePath`（**绝对路径**） |
| `text` | `text` | `content`、`fontFamily`、`fontSize`(24)、`color`、`bold`、`align`、`opacity`(100) |
| `table` | `table` | `rows`（数组的数组）、`headerColor`、`textColor`、`borderColor`、`fontSize`(16)、`showHeader`(true)、`alternateRow`(false) |
| `shape` | `shape` | `shapeType`（`rectangle`/`round_rect`/`ellipse`/`line`）、`fillColor`、`borderColor`、`borderWidth`(1) |
| `sticker` | `sticker` | `stickerType`（`title_line`/`corner_badge`/`star_rating`/`arrow`/`divider`/`card_border`）、`color`、以及下列条件字段 |

sticker 的条件字段：

| 键 | 写入条件 |
| --- | --- |
| `borderShape`（`rectangle`/`square`/`circle`/`ellipse`） | 仅 `card_border` |
| `imagePath`（项目内相对路径） | 仅 `card_border` 且非空 |
| `imageOffsetX` / `imageOffsetY`（0–1，0.5 居中） | 有 `imagePath` 且值 ≠ 0.5 |

颜色统一写作 `#rrggbb`（小写，**不保存 alpha**）；文本与署名的不透明度单独用 `opacity` 字段。
数值为整数时序列化输出为整数（如 `60` 而不是 `60.0`）。

## 4. 模板文件

模板顶层键：`formatVersion`(=1)、`name`、`type`、`description`、`pages`。
其中 `pages` 的元素结构与 `project.json` 的 page **完全一致**（含可选 `backgroundImage`）。

```json
{
    "formatVersion": 1,
    "name": "装备推荐",
    "type": "equipment",
    "description": "卡片网格展示装备图、名称与获取途径",
    "pages": [
        {
            "name": "页面 1",
            "width": 1080,
            "height": 1440,
            "components": [ /* 与 project.json 的 component 相同 */ ]
        }
    ]
}
```

读取校验：

- 非法 JSON / 根不是对象 → 失败（`文件不是有效的 JSON：%1`）
- `formatVersion` 小于 1 或大于当前值 → 失败
- `pages` 为空 → 失败（`模板不包含任何页面`）

## 5. 向后兼容规则

### 版本

- `formatVersion` 缺失 → 视为 1
- `< 1` → 拒绝：`格式版本 %1 不合法`
- `> 当前值` → 拒绝：`文件由更新版本的软件创建（格式版本 %1，当前支持 %2），请升级软件后打开`
- 目前**没有**逐版本迁移分支，只有字段级兼容

### 缺字段回退

- `walkthroughs` 不是数组 → 空列表；数组元素不是对象 → **跳过该条**（其余内容仍可打开）
- 页面尺寸非法或超限 → `1080×1440`
- 组件字段缺失 → 见上文默认值表
- 旧文件没有 `opacity` → 100（外观与旧版一致）
- 旧文件没有 `borderShape` / `imagePath` / 取景偏移 → 矩形 / 无图 / 居中
- 旧文件没有 `backgroundImage` → 无背景图
- 旧文件没有 `components` → 空组件列表
- 颜色键缺失 → 回退为**黑色**（注意：不是结构体里的默认色，见「已知坑」）

### 旧格式迁移

- 顶层 `articles` 非空数组 → 追加到**第一个攻略**的文章列表；若项目里没有任何攻略，
  则自动新建一个标题为 `迁移文章`、类型为 `custom` 的攻略来承载它
- 迁移只在读取时发生，**写回时不再产生顶层 `articles`**（数据被就地升级）

### 尺寸防线

读取时页面单边超过 **16384px** 会回退默认尺寸。写入侧不做裁剪——因此
「从图片新建页面」在导入超大图时会先等比缩小再作为页面尺寸。

## 6. 路径约定

| 用途 | 存储形式 |
| --- | --- |
| 图片组件的图片 | **绝对路径**（`AssetStore::importImage` 的返回值） |
| 页面背景图 `backgroundImage` | 项目内**相对路径** |
| 卡片边框图 `imagePath` | 项目内**相对路径** |
| 文章正文里的图片 | `assets/<文件名>` 相对路径；外部 URL 原样保留 |

`AssetStore` 提供两个转换函数：

- `toProjectRelative(abs, projectDir)`：转成项目内相对路径；不在项目内则保留绝对路径
- `resolvePath(path, projectDir)`：绝对路径原样返回，相对路径按项目目录拼接

> 由于图片组件存的是绝对路径，**整个项目文件夹被移动或改名后，图片组件可能失效**，
> 而背景图与卡片边框图不受影响。

## 7. 素材命名

`assets/` 下的文件名为 `QUuid::createUuid()`（无花括号）+ 原扩展名，例如
`6f1c8a4e-....png`。不保留原名、不做内容去重。

## 8. 已知坑（读写两侧）

- **颜色回退不一致**：读取时缺失的颜色键统一回退黑色，会覆盖结构体默认色
  （形状填充 `#e6e6e6`、贴纸 `#0078d7`、表格边框灰），旧数据可能因此变色。
- **`formatVersion` 没有迁移框架**：只有「拒绝更高版本」的逻辑。
- 模板读取失败的单个文件会被静默跳过（用户模板列表里看不到它，但也没有报错）。

设置项（QSettings 键名与默认值）见 [设置与快捷键](设置与快捷键.md)。
