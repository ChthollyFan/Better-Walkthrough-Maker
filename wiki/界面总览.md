# 界面总览

## 1. 窗口布局

窗口默认 1400×900（会记住上次的位置与大小），标题格式为
`项目名 - 更好的攻略制作器`，有未保存改动时项目名前会带 `*`。

界面由三段构成，中间用可拖动的分隔条隔开：

```
┌──────────────┬────────────────────────────────────┬──────────────┐
│              │                                    │  素材库 / 图层 │
│   项目结构    │        画布  或  文章编辑器          │  （标签页）    │
│ （左侧面板）  │      （中间，二者切换）              │  右侧面板     │
│              │                                    │              │
└──────────────┴────────────────────────────────────┴──────────────┘
```

| 区域 | 说明 |
| --- | --- |
| 左侧：项目结构 | 树形展示「项目 → 攻略 → 页面 / 文章」，单击节点切换编辑对象 |
| 中间：编辑区 | 选中页面时显示画布；选中文章时显示 Markdown 分栏编辑器 |
| 右侧：标签页 | `素材库`、`图层` 两个标签页；**默认停在「图层」** |

面板显示规则（没有独立的「视图」菜单，也不能把面板浮动/关闭）：

- 选中**页面**节点 → 中间切回画布，右侧标签页显示
- 选中**文章**节点 → 中间切到文章编辑器，右侧标签页**自动隐藏**（素材库与图层是画布专用）

打开项目后会自动选中第一个攻略的第一页，所以打开即可见画面。

## 2. 菜单栏

### 文件(&F)

| 菜单项 | 快捷键 | 说明 |
| --- | --- | --- |
| 新建项目… | `Ctrl+N` | 新建项目向导 |
| 打开项目… | `Ctrl+O` | 选择 `project.json` |
| 最近项目 ▸ | — | 最近 10 个项目，条目为 `project.json` 完整路径 |
| 保存 | `Ctrl+S` | 先把画布同步回数据模型再写盘 |
| 自动保存 | — | 可勾选开关，**每次启动默认开启**（不持久化） |
| 导出… | `Ctrl+E` | 打开导出对话框 |
| 设置… | `Ctrl+,` | 全局设置 |
| 退出 | — | 有关闭前未保存检查 |

### 攻略(&W)

| 菜单项 | 说明 |
| --- | --- |
| 新建攻略 | 从模板列表创建（含空白模板） |
| 新建页面 | 从尺寸预设创建页面 |
| 从图片新建页面… | 以图片原始尺寸建页，并把图片设为该页背景图 |
| 重命名… | 作用于当前选中节点（项目根 / 攻略 / 页面 / 文章） |
| 删除… | 同上，均有确认提示（项目根不可删除） |
| 保存为模板… | 把当前攻略存为项目模板 |
| 导入模板… | 从 `.json` 导入模板到当前项目 |
| 导出当前攻略为模板… | 把当前攻略导出成可分享的 `.json` |

### 插入(&I)

菜单项由插件注册表动态生成，当前共 13 项（**平铺、没有二级子菜单**）：

`图片`、`文本`、`表格`、`矩形`、`圆角矩形`、`椭圆`、`线条`、
`标题装饰线`、`角标`、`推荐度星标`、`箭头`、`分割线`、`卡片边框`

### 编辑(&E)

| 菜单项 | 快捷键 | 说明 |
| --- | --- | --- |
| 撤销 / 重做 | `Ctrl+Z` / `Ctrl+Y` | 撤销项名称随操作变化 |
| 剪切 / 复制 / 粘贴 | `Ctrl+X` / `Ctrl+C` / `Ctrl+V` | 作用于组件（应用内剪贴板，不写系统剪贴板） |
| 复制当前页到剪贴板 | `Ctrl+Shift+C` | 按 2x 渲染当前页写入**系统剪贴板** |
| 删除选中 | `Delete` | — |
| 全选 | `Ctrl+A` | — |
| 对齐 ▸ | — | 左 / 水平居中 / 右 / 顶 / 垂直居中 / 底（≥2 个组件） |
| 水平等距分布 / 垂直等距分布 | — | ≥3 个组件 |
| 网格吸附 | — | 可勾选，**默认开启**，间距 10px |
| 对齐参考线吸附 | — | 可勾选，**默认开启**，阈值 6px |

### 主题(&T)

- **界面外观**：`深色` / `浅色` / `跟随系统`（默认跟随系统）——只影响窗口与控件外观，不影响画布内容
- **画布配色**：内置仅有「浅色页面」一种，因此该分组当前不会显示；将来主题变多会自动出现

### 帮助(&H)

- **快捷键…**：弹窗列出常用快捷键
- **关于…**：版本号、功能简介、许可协议、运行时 Qt 版本

## 3. 工具栏与状态栏

只有一个工具栏，名称「插入」。默认**隐藏**，显示方式是在菜单栏「插入」菜单项上**右键**，
勾选 **显示插入工具栏**。显示后包含：

- 组件按钮：`图片`、`文本`、`表格`（只有两级路径的组件会出现在工具栏，形状与装饰不会）
- `撤销` / `重做`
- 六个对齐按钮
- `删除选中`

工具栏按钮为纯文字，没有图标。

状态栏只显示临时消息（无常驻控件，不显示缩放比例或坐标），例如：

| 消息 | 触发 |
| --- | --- |
| `就绪` | 启动 |
| `已打开项目：<目录>` | 打开成功（5 秒） |
| `已保存` / `设置已保存` | 手动保存 / 设置确定 |
| `已自动保存` | 自动保存成功（3 秒） |
| `已从上次未完成的保存恢复` | 崩溃恢复（5 秒） |
| `请先在左侧选择要编辑的页面` | 未选页面就点插入 |
| `请先选中至少两个组件` / `至少三个组件` | 对齐 / 分布条件不足 |
| `当前页已复制到剪贴板（2x），可直接粘贴使用` | `Ctrl+Shift+C` 成功 |
| `已复制 N 个组件` | 复制组件 |
