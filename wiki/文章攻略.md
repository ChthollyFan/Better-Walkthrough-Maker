# 文章攻略（Markdown）

一个攻略下可以同时包含**页面**（图文攻略，一页 = 一张 PNG）与**文章**（Markdown 攻略）。
文章是攻略的子级，在项目树里与页面同级。

## 1. 新建与导入文章

在项目树的**攻略节点**上右键：

| 菜单项 | 行为 |
| --- | --- |
| 新建文章… | 输入标题（默认 `文章 N`），正文初始为 `# <文章标题>` |
| 从文件导入文章… | 选择 `.md` / `.markdown` / `.txt`，标题取**文件名（去扩展名）** |

导入时对正文里的图片做如下处理：

- `http://` / `https://` 开头的地址、以及本来就是 `assets/` 的相对路径 → **原样保留**
- 其它相对路径的本地图片：若文件与 `.md` 同目录存在 → 复制进项目 `assets/`（UUID 命名），
  并把正文路径改写为 `assets/<文件名>`
- 找不到的图片保持原路径（之后可能失效）
- 正文里的 `![[W:P]]` 引用**原样保留**

文章正文内嵌在 `project.json` 中（不是独立的 `.md` 文件），详见 [数据格式](数据格式.md)。

## 2. 编辑器

选中文章节点后，中间区域切换为分栏编辑器：

```
┌────────────────────────┬────────────────────────┐
│  Markdown 源码（左）     │  实时预览（右，只读）    │
│  QTextEdit，等宽字体     │  渲染 CommonMark+GFM    │
└────────────────────────┴────────────────────────┘
```

- 源码改动后 **300ms 防抖**：到期才刷新预览并写回数据模型
- 预览中的图片宽度自动适配控件宽度，点击外链会用系统默认浏览器打开
- `Ctrl+滚轮`：预览整体缩放（**文字与图片同步**），范围 0.3–5.0

## 3. 工具栏

| 按钮 | 行为 |
| --- | --- |
| 加粗 | 选中文本用 `**` 包裹；无选中则插入 `****` 并把光标放在中间 |
| 斜体 | 同上，用 `*` |
| 标题 | 在选中行（可多行）行首插入 `## ` |
| 列表 | 在选中行（可多行）行首插入 `- ` |
| 链接 | 依次输入链接文字与地址，插入 `[文字](地址)`；取消或留空则中止 |
| 图片 | 选图；有项目时复制进 `assets/` 并插入 `![图片](assets/<文件名>)`，无项目时插入原路径 |
| 页面引用 | 打开图形化的页面选择器（见下） |

工具栏按钮为纯文字，**没有绑定快捷键**（源码框自己的 `Ctrl+Z/C/V/X/A` 是编辑框默认行为）。

## 4. 页面引用 `![[W:P]]`

这是本项目的**自定义 Markdown 语法**（标准 Markdown 不支持）：

```markdown
![[0:1]]
```

- `W` = 攻略索引（项目树中第几个攻略，从 0 开始）
- `P` = 该攻略下的页面索引（从 0 开始）

图形化插入：工具栏 **页面引用** → 在「选择要引用的页面」对话框中挑选
（条目格式 `攻略标题 - 页面名（第P页）`）→ 点「插入」。

渲染行为：

| 场景 | 效果 |
| --- | --- |
| 编辑器预览 | 渲染为该页面的图片（按 **0.5 倍率**渲染，避免预览过大） |
| 文章 PNG / PDF 导出 | 渲染为页面图片 |
| 导出 Markdown | 原版 `.md` 保留 `![[W:P]]`；兼容版 `_compatible.md` 替换为 `images/page_W_P.png` |

> ⚠️ 引用**没有越界校验**：引用不存在的攻略 / 页面时，预览与导出会静默跳过（显示为空或坏图），
> 编辑器不报错。删除页面后已有引用也不会自动修正，索引会前移指向别的页面——
> **删除页面后请手动检查文章引用**。

## 5. 导出文章

文章支持三种导出格式（在导出对话框中根据选中的对象自动切换）：

- **Markdown**：`<标题>.md`（原文）+ `<标题>_compatible.md`（引用换成图片）+ `images/` 目录
- **PNG 长图**：宽度固定 1080，高度自适应，可加水印署名，超过 30000px 会提示拆分
- **PDF**：A4 分页，署名为文末一行

各格式的细节、署名设置与限制见 [导出](导出.md)。

## 6. 主题联动

文章预览与导出（PNG / PDF）的**文字颜色跟随当前画布主题**，导出图底色也用主题背景色。
深色主题下会自动使用浅色文字，不会出现黑字黑底。

## 7. 尚未支持

语法高亮、查找替换、字数统计、大纲 / 目录、滚动同步、页面引用尺寸控制
（如 `![[0:0|600]]`）、自动 TOC、导出时选择浅色 / 深色主题等均未实现。
