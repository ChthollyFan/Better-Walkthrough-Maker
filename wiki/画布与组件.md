# 画布与组件

## 1. 画布操作

### 视图

| 操作 | 说明 |
| --- | --- |
| `Ctrl+滚轮` | 以鼠标位置为中心缩放，范围 **10% – 800%**，每格 ×1.15 |
| 普通滚轮 | 上下滚动画布 |
| 切换页面 / 打开项目 | 自动「适应窗口」并居中 |
| 插入组件后 | 自动选中新组件并滚动到它 |

画布背景就是页面本身：主题背景色 + 可选的页面背景图，尺寸严格等于页面尺寸
（**拖到页面外的组件不会把画布撑大**，导出时也会被裁掉）。

### 鼠标

| 操作 | 结果 |
| --- | --- |
| 左键单击组件 | 选中该组件（`Ctrl` 加选） |
| 拖动组件内部 | 移动；若该组件已在选中集合里，其余选中组件按同一位移一起移动 |
| 拖动空白处 | **框选** |
| 拖动 8 个缩放手柄 | 缩放该组件（最小边长 8px；手柄只在组件选中后可命中） |
| 拖动顶部上方约 24px 的圆点 | 自由旋转，**无角度吸附** |
| 双击组件 | 编辑内容（见第 4 节） |
| 右键组件 / 空白处 | 右键菜单（见第 5 节） |

鼠标悬停到手柄时光标会变化（斜向 / 水平 / 垂直 / 旋转）。

### 吸附

两种吸附默认都**开启**，在 **编辑** 菜单里切换：

| 吸附 | 规则 |
| --- | --- |
| 网格吸附 | 网格间距 **10px**；缩放 ≥ 50% 时画布上会显示网格线 |
| 对齐参考线吸附 | 阈值 **6px**；候选线来自其它组件的左 / 中 / 右、上 / 中 / 下 |

注意：吸附只改变坐标，**画布上不会绘制提示线**；缩放时吸附作用于组件**左上角**；
多选拖动时只对「被按下的那个组件」计算吸附，其余组件套用同一位移。

> 目前**没有**标尺、也没有可拖出的自定义参考线；方向键微调、`Shift` 等比缩放、
> `Alt` 中心缩放、旋转角度吸附均未实现。

## 2. 五类组件

| 组件 | 插入默认尺寸 | 说明 |
| --- | --- | --- |
| 图片 | 300×200 | 从文件选择，自动复制进项目 `assets/`；可缩放、旋转 |
| 文本 | 300×60 | 单行文本 + 字体 / 字号 / 加粗 / 颜色 / 不透明度 / 对齐 |
| 表格 | 420×200 | 默认 3×3 示例数据；可编辑、可从剪贴板导入 CSV |
| 形状 | 200×120 | 矩形 / 圆角矩形 / 椭圆 / 线条，填充色与描边色 |
| 贴纸（装饰） | 见下 | 标题装饰线 320×16、角标 60×40、推荐度星标 160×28、箭头 120×40、分割线 320×12、卡片边框 320×180 |

新建组件的默认配色跟随当前主题（文本取主题文字色，形状取辅色 / 主色，贴纸取主色）。
**切换主题不会改写已有组件的颜色**，只影响新插入的组件与画布底色。

### 文本

`插入 → 文本` 会直接弹出「文本样式」对话框（内容、对齐、字体、字号、加粗、颜色、不透明度、
预览），双击已有文本也会打开同一个对话框。

- 对齐选项：左对齐 / 居中 / 右对齐 / 两端对齐
- 默认字体 `Microsoft YaHei`，默认字号 24，默认不透明度 100
- 若没有改动「水平对齐」，写回时会保留原有对齐值（避免历史项目的文本垂直位置跳变）

### 表格

双击表格打开「编辑表格」对话框：`QTableWidget` + `加行` / `加列` / `删行` / `删列` /
`从剪贴板导入 CSV`。

- 导入 CSV 时：按行切分、跳过空行；每行**优先按 Tab 拆列，否则按逗号**；按最大列数重建表格
- 该对话框**只改数据**，表头色、斑马纹、字号等样式保持不变
- 数据为空时默认给 3 行 4 列

### 形状

矩形 / 圆角矩形 / 椭圆 / 线条，插入后**没有**内容编辑入口（双击无反应）；
颜色等样式目前没有编辑对话框。

### 贴纸（装饰）

双击已有贴纸：

- **卡片边框** → 打开「卡片边框」对话框
- 其它贴纸 → 弹系统颜色选择框，修改贴纸颜色

## 3. 卡片边框（重点）

卡片边框 = 一个可放图的装饰框，常用于装备 / 地图卡片。

对话框选项：

| 选项 | 说明 |
| --- | --- |
| 边框形状 | 矩形（圆角）/ 正方形 / 圆形 / 椭圆 |
| 边框颜色 | 色块按钮（显示十六进制值） |
| 框内图片 | `选择图片…` / `清除`；图片复制进项目 `assets/` 并存**项目内相对路径** |
| 水平位置 / 垂直位置 | 0–100 的取景滑块（无图片时禁用），0.5 为居中 |
| 预览 | 240×150，与画布、导出使用同一套绘制实现 |

行为约定：

- 图片按「等比覆盖」铺满外框，然后按形状裁剪（圆形 / 椭圆的四角自然被裁掉），
  最后描边框线——线在图片之上，不会被盖住
- 形状选择**正方形 / 圆形**时，确定后组件尺寸会归一为 **1:1**（以短边为准，位置不变）
- `清除` 只清引用，素材文件仍留在素材库，取景位置重置为居中

## 4. 双击编辑一览

| 组件 | 双击结果 |
| --- | --- |
| 文本 | 文本样式对话框（内容 / 对齐 / 字体 / 字号 / 加粗 / 颜色 / 不透明度） |
| 表格 | 编辑表格对话框（含从剪贴板导入 CSV） |
| 卡片边框 | 卡片边框对话框（形状 / 颜色 / 框内图片 / 取景） |
| 其它贴纸 | 颜色选择框 |
| 图片 | 无反应 |
| 形状 | 无反应 |

> 图片组件目前**没有替换图片的入口**（双击与右键都没有），需要换图时只能删除后重新插入。

## 5. 右键菜单

在画布上点右键，先命中最上层组件并选中它，然后弹出菜单：

| 菜单项 | 启用条件 |
| --- | --- |
| 剪切 | 有选中组件 |
| 复制 | 有选中组件 |
| 粘贴 | 应用内剪贴板非空 |
| 删除 | 有选中组件 |
| 置顶 / 置底 | 有选中组件 |
| 编辑文本… / 编辑表格… / 编辑贴纸… / 编辑卡片边框… | 仅当点中的是文本 / 表格 / 其它贴纸 / 卡片边框；图片与形状没有编辑项 |
| 锁定 / 解除锁定 | 点中了任意组件 |

行为细节：

- **剪切** = 复制 + 删除；**复制**写入应用内剪贴板（不写系统剪贴板）
- **粘贴**偏移 `+20,+20`，重新生成 ID，并置于最上层；粘贴后不会自动选中新组件
- **置顶** = 最大 `zOrder` + 1；**置底** = 最小 `zOrder` − 1
- **锁定**的组件不能拖动 / 缩放 / 旋转，但仍能被框选中、被图层面板选中，可右键解除锁定
- 命中检测使用**未考虑旋转的轴对齐矩形**，旋转后的组件命中区域仍是原矩形

## 6. 图层

右侧 `图层` 标签页（画布模式下可见）：

- 列表**第一行是最底层**，最后一行是最顶层
- 行文本：图片 `图片`、形状 `形状`、表格 `表格`、贴纸 `贴纸`、文本取**内容前 12 个字符**
- 每行前方的复选框控制**可见性**：取消勾选后组件在画布上隐藏，**导出时也会被跳过**
  （隐藏后无法在画布上点选，需要回到图层面板重新勾选）
- 单击某行：清空其它选择、只选中该组件，并把视图滚动到它
- 底部按钮：`上移` / `下移` / `置顶` / `置底`（与相邻层交换 `zOrder`）

## 7. 对齐与分布

在 **编辑** 菜单：

- **对齐**：左 / 水平居中 / 右 / 顶 / 垂直居中 / 底，需选中 **≥2** 个组件，基准是选中集的包围盒
- **等距分布**：水平 / 垂直，需选中 **≥3** 个组件；按主轴排序后让相邻间隙相等
  （首组件起点到末组件终点区间内均分，间隙可能为负）

## 8. 撤销 / 重做

- `Ctrl+Z` / `Ctrl+Y`，撤销栈只在内存中，不限步数
- **可撤销**：拖动 / 缩放 / 旋转、双击改内容、粘贴、对齐、等距分布
- **不可撤销**：插入组件、删除选中、置顶 / 置底、图层的层序与可见性改动、锁定 / 解锁、
  项目树里的增删改（攻略 / 页面 / 文章）
- 撤销采用**整页组件快照**实现，因此撤销后画布的选择状态会丢失

## 9. 复制到系统剪贴板

**编辑 → 复制当前页到剪贴板**（`Ctrl+Shift+C`）：把当前页按 **2x** 渲染成图片写入系统剪贴板，
可直接粘贴到平台编辑器中（渲染时不绘制作者署名水印）。
