# 导出

入口：**文件 → 导出…**（`Ctrl+E`）。未打开项目时会提示 `请先打开项目`。

导出对话框会**根据左侧选中的对象自动切换模式**：

- 选中**文章**节点 → 文章导出模式（窗口标题 `导出文章`）
- 其它情况 → 页面导出模式（窗口标题 `导出`）

## 1. 页面导出（图文攻略）

| 选项 | 可选值 | 默认 |
| --- | --- | --- |
| 导出范围 | 当前页 / 当前攻略全部页 | 当前页 |
| 导出格式 | 逐页 PNG / 长图（纵向拼接） | 列表第一项（逐页 PNG） |
| 分辨率倍率 | 1x（原尺寸）/ 2x（推荐，抗平台压缩）/ 3x | **2x** |
| 添加作者署名 | 复选框 | 已填作者名 → 默认勾选；未填 → 禁用并提示去设置里填写 |
| 署名设置… | 按钮 | 未勾选署名时禁用 |
| 导出到 | 目录输入框 + `浏览…` | 上次使用的导出目录 |

- 范围选「当前页」时，**导出格式下拉会被禁用**（单页导出时长图与逐页结果相同）
- 对话框底部固定提示：长图会把所选范围内的页面纵向拼接；若只有一个页面，长图与逐页结果相同

### 产物

| 格式 | 文件名 | 说明 |
| --- | --- | --- |
| 逐页 PNG | `<攻略名>_01.png`、`_02.png`… | 序号两位补零；导出中显示可取消的进度框（取消后已导出的文件保留） |
| 长图 | `<攻略名>_长图.png` | 页面之间绘制 **20px 的灰色（rgb(200,200,200)）分隔线**；宽度取各页最大宽度，窄页用背景色补底 |

文件名净化规则：`\ / : * ? " < > |` 替换为 `_`，标题为空时回退为 `攻略`。

尺寸规则：

- 单页 = 页面尺寸 × 倍率
- 长图 = 各页高度之和 × 倍率
- 长图总高度上限 **30000px**（按页面逻辑像素判定），超限会报错
  「长图总高度过大（Xpx，上限 30000px），请减少页数或拆分导出」，**不会自动分片**

## 2. 文章导出

文章模式下格式下拉只列出支持文章的格式，同时隐藏「导出范围」分组与分辨率倍率下拉框
（倍率的标签行仍会显示，属已知的界面小瑕疵）：

| 格式 | 产物 | 署名 |
| --- | --- | --- |
| Markdown 文件（.md + 图片） | `<标题>.md` + `<标题>_compatible.md` + `images/` 目录 | **不追加**（保持原文纯净） |
| PNG 长图（整篇文章渲染为一张图） | `<标题>.png`，宽度固定 **1080**，高度按内容自适应 | 四角水印 |
| PDF 文档（分页） | `<标题>.pdf`，A4 自动分页 | 文末一行 `— by <作者名>` |

### Markdown 导出的三个产物

1. **`<标题>.md`**：正文**原样输出**，保留 `![[W:P]]` 页面引用与 `assets/xxx.png` 相对路径
2. **`<标题>_compatible.md`**：把 `![[W:P]]` 替换为标准图片语法
   `![页面W:P](images/page_W_P.png)`，外部 Markdown 阅读器可直接查看；
   正文里的普通图片也会复制进 `images/` 并改写路径
3. **`images/`**：页面引用渲染图（`page_W_P.png`，1.0 倍率）+ 被引用的素材副本

若某个页面引用渲染失败，兼容版会保留 `![[W:P]]` 原文而不生成图片。

### 文章长图与 PDF 的限制

- 文章 PNG 长图高度超过 **30000px** 会提示「文章过长…请拆分文章后导出」并中止
- PDF 的署名为**文末文本行**：位置与不透明度设置对 PDF 不生效，字体 / 字号 / 加粗 / 颜色生效
- 文章标题净化为空时 Markdown 导出会失败返回；**目前没有页面型的 PDF 导出**

## 3. 作者署名与水印

署名文本固定为 `by <作者名>`，作者名在 **文件 → 设置 → 作者署名** 里填写。

导出对话框的 `署名设置…` 打开「署名设置」对话框：

| 选项 | 范围 / 默认 |
| --- | --- |
| 水印位置 | 左上角 / 右上角 / 左下角 / **右下角（默认）** |
| 字体 | 系统字体，默认 `Microsoft YaHei` |
| 字号 | 6–400 px，默认 **18** |
| 样式 | 加粗（默认不加粗） |
| 颜色 | 颜色选择器，默认黑色 |
| 不透明度 | 0–100，默认 **63** |

- 对话框内的预览是按 640×400 模拟页面、1x 绘制的，复用了导出同一条绘制路径，所见即所得
- 点「确定」即写入全局设置，下次导出沿用

字号缩放规则：

| 场景 | 缩放系数 |
| --- | --- |
| 页面导出 | 导出倍率（2x 时字号 ×2） |
| 文章 PNG 长图 | 图片宽度 / 720（1080 宽 → ×1.5） |
| 复制当前页到剪贴板 | 无署名 |

## 4. 导出结果

导出成功后弹出「导出完成」提示框，显示成功数量与目标目录，按钮：

- **打开目录**：用系统资源管理器打开导出目录
- **Close**：关闭

同时程序会记住该目录，作为下次导出的默认目录。

## 5. 其它输出方式

| 方式 | 说明 |
| --- | --- |
| 复制当前页到剪贴板（`Ctrl+Shift+C`） | 按 2x 渲染当前页写入**系统剪贴板**，可直接粘贴进平台编辑器；不画署名 |
| 复制 / 粘贴组件（`Ctrl+C` / `Ctrl+V`） | 组件级的应用内剪贴板，用于在页面之间搬运组件 |

## 6. 尚未支持

GIF 导出、自动分片导出、长图分隔线样式自定义、页面型 PDF、SVG 导出等均未实现。
