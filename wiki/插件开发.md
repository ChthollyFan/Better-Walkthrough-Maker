# 插件开发

本项目从 M1 起就按「可插件化」设计：所有扩展点都通过统一的 `PluginHost` 注册与查询，
主窗口的菜单、工具栏、导出下拉框等**全部从 `PluginHost` 动态查询构建**。

当前阶段是**编译时静态注册**（内置功能本身就是一组 Provider 适配器），
以**运行时动态库加载**为最终目标（升级路径已预留，尚未实现）。

## 1. 扩展点一览

所有接口位于 `src/plugin/`，命名空间 `bwm`：

| 扩展点 | 接口 | 内置实现数量 |
| --- | --- | --- |
| 组件类型 | `IComponentProvider` | 13 |
| 导出格式 | `IExportProvider` | 5 |
| 面板 / 视图 | `IPanelProvider` | 0（尚未接入，见「已知缺口」） |
| 模板包 | `ITemplateProvider` | 1 |
| 主题（画布配色） | `IThemeProvider` | 1 |
| 界面外观 | `IUiStyleProvider` | 1 |

## 2. PluginHost

`src/plugin/PluginHost.h`，继承 `QObject`，由 `MainWindow` 创建并持有：

```cpp
void registerComponentProvider(IComponentProvider* pProvider);
const QVector<IComponentProvider*>& componentProviders() const;
// registerExportProvider / exportProviders
// registerPanelProvider   / panelProviders
// registerTemplateProvider/ templateProviders
// registerThemeProvider   / themeProviders
// registerUiStyleProvider / uiStyleProviders
```

约定：

- **注册只存指针，不负责销毁**：Provider 的所有权归调用方（通常是函数内 `static` 对象）
- 不去重、不校验重复注册；查询按注册顺序返回
- 新增 Provider 后框架自动出现对应菜项 / 工具栏按钮 / 导出格式 / 模板 / 主题，无需改框架代码

## 3. PluginContext

每次调用插件方法时由框架构造并传入（`src/plugin/PluginContext.h`）：

| 字段 | 类型 | 含义 |
| --- | --- | --- |
| `theme` | `Theme` | 当前画布配色（主色 / 辅色 / 背景色 / 文字色） |
| `defaultPageSize` | `QSize` | 全局默认画布尺寸 |
| `projectDirectory` | `QString` | 当前项目目录（解析项目内相对路径用），无项目时为空 |
| `pCurrentPage` | `Page*` | 当前编辑页面，无选中时为 `nullptr` |
| `authorMarkStyle` | `AuthorMarkStyle` | 署名水印样式（由导出对话框写入） |

> 注意：`docs/plugin-component-dev.md` 中的字段清单是历史版本，**缺少 `authorMarkStyle`**，
> 以本页与代码为准。

## 4. 接口签名

### IComponentProvider（组件类型）

```cpp
class IComponentProvider {
public:
    virtual ~IComponentProvider() = default;
    virtual QString typeId() const = 0;          // 唯一标识，如 "builtin.image"
    virtual QString displayName() const = 0;     // 用户可见名称（菜单 / 工具栏文字）
    virtual QString menuPath() const = 0;        // 菜单路径，'/' 分隔，如 "插入/形状/矩形"
    virtual Component createComponent(const PluginContext& rContext) const = 0;
    virtual bool requiresInputDialog() const;    // 默认 false
    virtual bool showInputDialog(QWidget* pParent, Component& rComponent,
                                 const PluginContext& rContext) const;  // 默认 false
};
```

- `createComponent()` 负责设置 `eType`、尺寸与类型专属数据；`id` / `zOrder` 由画布分配
- `requiresInputDialog()` 返回 `true` 时框架会调用 `showInputDialog()`；
  返回 `true` 表示确认插入，`false` 表示取消
- `menuPath()` 目前**只用于工具栏过滤**（只有两级路径的组件会出现在工具栏），
  菜单本身是平铺的

### IExportProvider（导出格式）

```cpp
class IExportProvider {
public:
    virtual ~IExportProvider() = default;
    virtual QString formatId() const = 0;        // 如 "builtin.png.separate"
    virtual QString displayName() const = 0;     // 如 "逐页 PNG"
    virtual int exportPages(const QVector<Page>& vecPages,
                            const QString& rWalkthroughTitle,
                            const QString& strDirPath,
                            qreal dScale,
                            const QString& strAuthor,
                            const PluginContext& rContext,
                            QWidget* pParent) const = 0;
    virtual bool supportsArticle() const;        // 默认 false
    virtual int exportArticle(const Article& rArticle,
                              const Project& rProject,
                              const QString& rArticleTitle,
                              const QString& strDirPath,
                              const QString& strAuthor,
                              const PluginContext& rContext,
                              QWidget* pParent) const;   // 默认返回 0
};
```

- 返回值是**成功导出的文件数量**，`0` 表示失败（对话框会提示「导出失败，请检查目录权限」）
- 导出是同步操作，长任务请自行考虑进度框或异步方案
- 文件名净化、进度显示、写文件都由 Provider 自己负责
- 署名样式通过 `rContext.authorMarkStyle` 传入，**不需要改接口签名**，第三方插件保持兼容

### IPanelProvider（面板 / 视图）

```cpp
class IPanelProvider {
public:
    virtual ~IPanelProvider() = default;
    virtual QString panelId() const = 0;
    virtual QString displayName() const = 0;
    virtual QWidget* createPanel(QWidget* pParent, PluginHost* pHost,
                                 CanvasScene* pScene, CanvasView* pView,
                                 ProjectManager* pProjectManager) = 0;
};
```

返回的控件所有权归调用方（即被 `addTab` 的 `QTabWidget`）。

### ITemplateProvider（模板包）

```cpp
class ITemplateProvider {
public:
    virtual ~ITemplateProvider() = default;
    virtual QString providerId() const = 0;
    virtual QVector<Template> templates(const QString& rProjectDir) const = 0;
};
```

### IThemeProvider（画布配色）

```cpp
class IThemeProvider {
public:
    virtual ~IThemeProvider() = default;
    virtual QString providerId() const = 0;
    virtual QVector<Theme> themes() const = 0;
};
```

### IUiStyleProvider（界面外观）

```cpp
struct UiStyleDescriptor { QString strId; QString strDisplayName; bool bRequiresNativeApi = false; };

class IUiStyleProvider {
public:
    virtual QString providerId() const = 0;
    virtual QVector<UiStyleDescriptor> styles() const = 0;
    virtual bool applyStyle(const QString& strStyleId, QWidget* pMainWindow) const = 0;
    virtual bool paintBackground(const QString&, QWidget*, QPainter&) const;  // 默认 false
    virtual QColor canvasBackgroundColor(const QString&) const;               // 默认无效色
};
```

> `IUiStyleProvider` 是**第 6 类扩展点**，`AGENTS.md` 的表格与 `docs/` 下的五份插件开发文档
> 都没有覆盖它；对应实现是 `src/ui/GlassStyleProvider.*` 与静态管理器 `ui/UiStyle.h`。

## 5. 内置 Provider 清单

### 组件（13 个，注册顺序即菜单顺序）

| typeId | 菜单名 | 默认尺寸 |
| --- | --- | --- |
| `builtin.image` | 图片 | 300×200（弹文件框，复制进 `assets/`） |
| `builtin.text` | 文本 | 300×60（弹文本样式对话框） |
| `builtin.table` | 表格 | 420×200（带 3×3 示例数据） |
| `builtin.shape.0` … `.3` | 矩形 / 圆角矩形 / 椭圆 / 线条 | 200×120（颜色取主题） |
| `builtin.sticker.0` … `.5` | 标题装饰线 / 角标 / 推荐度星标 / 箭头 / 分割线 / 卡片边框 | 见 [画布与组件](画布与组件.md)；卡片边框弹对话框 |

### 导出（5 个）

| formatId | 显示名 | 文章支持 |
| --- | --- | --- |
| `builtin.png.separate` | 逐页 PNG | 否 |
| `builtin.png.longimage` | 长图（纵向拼接） | 否 |
| `article.markdown` | Markdown 文件（.md + 图片） | 是 |
| `article.png.longimage` | PNG 长图 | 是 |
| `article.pdf` | PDF 文档（分页） | 是 |

### 其它

- 模板：`BuiltinTemplateProvider`（`providerId = "builtin"`）转发 `TemplateManager::allTemplates()`
- 主题：`BuiltinThemeProvider`（`providerId = "builtin"`）遍历 `ThemeManager::themeNames()`
- 界面外观：`GlassStyleProvider`（`providerId = "builtin-ui"`），
  提供 `dark` / `light` / `auto` 三种风格，并同时注册到 `UiStyleManager`

## 6. 注册流程

`src/plugin/builtin/BuiltinPluginRegistrar.cpp`：

```cpp
void registerBuiltinPlugins(PluginHost* pHost)
{
    if(!pHost) { return; }
    static ImageComponentProvider* s_pImage = new ImageComponentProvider();
    pHost->registerComponentProvider(s_pImage);
    // …其余 Provider 同理
}
```

- Provider 用**函数内 `static` 指针 + `new`** 创建：生命周期贯穿整个应用，重复调用不会重建
- 在 `MainWindow` 构造时调用一次
- 新增内置 Provider 需要同时修改 `src/CMakeLists.txt` 把它加入 `bwm_core`

主窗口侧的消费位置：

| 扩展点 | 消费位置 |
| --- | --- |
| 组件 | `MainWindow` 构建插入菜单 / 工具栏；`insertComponent()` 执行插入 |
| 导出 | `ExportDialog` 填充格式下拉框并按 `supportsArticle()` 过滤 |
| 模板 | `ProjectTreePanel` 打开「新建攻略」对话框时合并列表 |
| 主题 / 界面外观 | `MainWindow` 构建主题菜单 |

## 7. 扩展示例

### 新增一个组件类型

1. 确定数据模型：能复用现有五类数据就直接复用，否则扩展 `core/Component.h` 与
   `ComponentSerializer`（会带来格式兼容负担）
2. 新建 Provider（建议放 `src/plugin/builtin/`，第三方放 `src/plugin/custom/`）
3. 实现 `typeId` / `displayName` / `menuPath` / `createComponent`
4. 在 `registerBuiltinPlugins()` 里注册
5. 把 `.cpp` 加入 `src/CMakeLists.txt` 的 `bwm_core`
6. 在 `core/ComponentPainter.cpp` 增加绘制分支（编辑器与导出共用）
7. 如需输入对话框，优先复用 `TextStyleDialog` / `CardBorderDialog` / `ui/FontSelectWidget`，
   这类对话框统一放 `plugin/builtin/` 层
8. 补测试：序列化往返 + 渲染像素断言

### 新增一个导出格式

实现 `IExportProvider`（页面型实现 `exportPages`；文章型把 `supportsArticle()` 返回 `true`
并实现 `exportArticle`），注册后自动出现在导出对话框的格式下拉中。
命名净化可参考内置 Provider 里的 `sanitizeFileName` 写法。

### 新增一个模板包 / 主题

分别实现 `ITemplateProvider` / `IThemeProvider`，注册后自动合并到「新建攻略」列表与主题菜单。

## 8. 已知缺口

| 缺口 | 现状 |
| --- | --- |
| 动态库加载 | `PluginHost::loadPlugins()` 只有 TODO 注释，无 `QPluginLoader` 代码、无 `plugins/` 目录约定、无插件元数据与 ABI 校验 |
| 面板扩展点未接通 | `IPanelProvider` 与 `panelProviders()` 已定义但没有任何 Provider，内置面板仍由 `MainWindow` 直接 `new` 并 `addTab` |
| 菜单不是多级的 | `menuPath()` 未驱动菜单结构，插入菜单是平铺的 |
| 主题管理是静态的 | `ThemeManager` 硬编码内置主题，插件主题能进菜单但 `currentTheme()` 仍返回内置主题；同名主题取先注册者 |
| 文档滞后 | `docs/plugin-component-dev.md` 缺 `authorMarkStyle`；`docs/plugin-export-dev.md` 未列 `supportsArticle` / `exportArticle`；五份文档都没有覆盖 `IUiStyleProvider` |
| 缺少插件测试 | `tests/plugin/` 下只有两个内置对话框的测试，没有 `PluginHost` 与注册流程的测试 |
