# 常见问题

## 使用相关

**Q：下载下来只有一个 exe，需要装 Qt 吗？**
不需要。发布产物是单文件 `BWM.exe`，Qt 运行时已打包在内，双击即可运行。
首次启动会稍慢，属于虚拟文件系统的初始化开销。

**Q：为什么「插入工具栏」不见了？**
插入工具栏默认隐藏。在菜单栏的 **插入** 菜单项上**右键**，勾选 `显示插入工具栏` 即可。

**Q：为什么「主题」菜单里看不到「画布配色」？**
内置画布配色只有「浅色页面」一种，程序在主题数量 ≤1 时不显示该分组。
界面深浅色在「界面外观」分组里（深色 / 浅色 / 跟随系统）。

**Q：导出的图会不会被平台压得太糊？**
默认导出倍率是 **2x**，并可在导出对话框改成 3x。平台会压缩图片，宁大勿小。

**Q：怎么把图直接贴到平台编辑器里？**
用 **编辑 → 复制当前页到剪贴板**（`Ctrl+Shift+C`），按 2x 渲染后写入系统剪贴板，直接粘贴即可。

**Q：可以拖图片进画布吗？**
目前全程序**不支持拖放**（资源管理器拖入、节点排序、图层排序都不支持）。
请用 `插入 → 图片`、素材库的 `导入素材…`，或文章工具栏的「图片」按钮。

**Q：图片组件的图怎么替换？**
目前**没有**替换入口（双击与右键都没有）。只能删除组件后重新插入。

**Q：删了组件 / 页面，能撤销吗？**
拖动、缩放、旋转、改内容、粘贴、对齐、分布**可以**撤销；
**插入组件、删除、置顶置底、图层操作、项目树里的增删改都不能撤销**。

**Q：隐藏的组件会被导出吗？**
不会。图层面板里取消勾选的组件在画布上隐藏，导出时也会被跳过（数据仍在项目里）。

**Q：为什么对齐 / 分布按钮没反应？**
对齐需要选中 **≥2** 个组件，等距分布需要 **≥3** 个组件，条件不足时只在状态栏提示。

**Q：文章里的 `![[0:1]]` 是什么？**
是本项目自定义的**页面引用**语法，表示引用第 0 个攻略的第 1 个页面。
详见 [文章攻略](文章攻略.md)。

**Q：把整个 `.bwm` 文件夹拷到别的电脑，图片还能显示吗？**
页面背景图与卡片边框图会自动跟着走（存的是项目内相对路径）；
但**图片组件存的是素材绝对路径**，换机器或移动项目文件夹后可能找不到图片，需要重新插入。
建议在项目做完、位置确定后再批量插图。

**Q：`project.json` 意外损坏打不开怎么办？**
先看同目录有没有 `project.json.tmp`：若存在且比 `project.json` 新，程序打开项目时会提示恢复。
注意：**由于已知缺陷，这个提示通常不会触发**（见下方「已知问题」），
因此请养成 `Ctrl+S` 的习惯，并定期备份整个 `.bwm` 文件夹。

**Q：可以同时打开两个项目吗？**
不可以，程序一次只打开一个项目，切换项目请用「文件 → 打开项目」。

**Q：有 Mac / Linux 版吗？**
代码基于 Qt 6，具备跨平台潜力，但目前只提供 Windows 构建与发布。

## 已知问题

| 问题 | 说明 | 规避方式 |
| --- | --- | --- |
| 崩溃恢复提示通常不触发 | 保存使用 `QSaveFile`，其临时文件名为 `project.json.<随机字符>`，而恢复逻辑查找的是 `project.json.tmp`，两者不一致 | 勤用 `Ctrl+S`；定期备份项目文件夹 |
| 移动项目后图片组件失效 | 图片组件保存的是素材绝对路径 | 项目定稿后再插图，或手工编辑 `project.json` 修复路径 |
| 删除页面后文章引用错位 | 页面引用按索引定位，删除页面后索引前移，引用不会自动修正，也没有越界提示 | 删除页面后检查文章中的 `![[W:P]]` |
| 素材删除不检查文章引用 | 引用检查只覆盖页面背景图、图片组件、卡片边框图，正文里的 `![](assets/…)` 不算 | 删除素材前先检查文章正文 |
| 长图高度上限按逻辑像素判定 | 上限 30000px 在缩放前判定，2x / 3x 导出时实际位图更高，可能因内存不足失败 | 页数多时降低倍率或拆分导出 |
| 旋转后组件的命中区域仍是原矩形 | 命中检测是轴对齐矩形 | 旋转幅度大时从图层面板选中 |
| 文章导出模式残留一行空的「分辨率倍率」标签 | 该控件在文章模式下隐藏，但标签行未隐藏 | 无影响，后续版本修复 |
| 自动保存间隔重启后回到 5 分钟 | 设置里的间隔只在「打开设置对话框并确定、且当时已有打开的项目」时才会应用到当前会话；程序启动时没有把设置同步给项目管理器 | 每次改完间隔后重新确认，或改后立即触发一次手动保存 |
| 未配置过颜色的旧数据可能变黑 | 读取时缺失的颜色键统一回退黑色（结构体默认值不生效） | 重新设置组件颜色 |

## 尚未实现（功能清单）

以下功能在当前版本中**还没有**，请不要按「应该有」来预期：

- **画布**：标尺、可拖出的参考线、吸附提示线、方向键微调、旋转角度吸附、
  `Shift` 等比缩放、编组、组件跨攻略移动
- **项目**：项目级自定义主题目录（`themes/`）、页面 / 攻略的复制粘贴与排序、双击节点重命名
- **素材**：重命名、排序、分类标签、拖放导入
- **图层**：拖拽排序、重命名、删除按钮
- **模板**：占位符 / 变量、在线模板市场
- **导出**：GIF、页面型 PDF、SVG、自动分片导出、长图分隔线样式自定义
- **文章**：语法高亮、查找替换、字数统计、TOC、页面引用尺寸控制、滚动同步
- **其它**：国际化的界面语言切换、快捷键自定义、拖放支持、云同步、安装包（NSIS / Inno Setup）
