# 快速开始

本篇用五分钟带你从零做出一张攻略图并导出成 PNG。

## 1. 获取软件

发布产物只有一个：**单文件 `BWM.exe`**，免安装、无需 Qt DLL。

- 从 [Releases](https://github.com/ChthollyFan/Better-Walkthrough-Maker/releases) 下载 `BWM.exe`
- 放到任意目录（建议单独放一个文件夹），双击运行

> 单文件版首次启动会稍慢：程序需要先解压内置的 Qt 运行时。

## 2. 新建项目

1. 菜单 **文件 → 新建项目…**（`Ctrl+N`）
2. 填写：
   - **游戏名**，例如 `艾尔登法环`
   - **默认画布尺寸**，四选一：

     | 预设 | 尺寸 | 适用 |
     | --- | --- | --- |
     | 竖图 | 1080×1440（默认） | 大多数图文攻略 |
     | 横图 | 1920×1080 | 宽幅对比图 |
     | 方形 | 1080×1080 | 社交平台方图 |
     | 长图 | 1080×2400 | 内容较多的长页 |

3. 点 **创建**，再选一个**项目保存位置**。

程序会在该位置创建 `<游戏名>.bwm/` 文件夹，里面包含：

```
艾尔登法环.bwm/
├── project.json     # 全部数据（攻略 / 页面 / 组件 / 文章）
└── assets/          # 导入的素材原图
```

项目**自包含**：整个文件夹可以备份、拷贝、发给别人。创建后会自动带上
一个攻略「攻略 1」和一页「页面 1」，并已选中该页。

> ⚠️ 注意：目前**图片组件保存的是素材的绝对路径**，所以项目文件夹改名或换机器后，
> 已插入的图片可能显示不出来，需要重新插入；页面背景图与卡片边框图不受影响。
> 建议项目定稿后再集中插图。详见 [常见问题](常见问题.md)。

## 3. 插入第一个组件

在画布上放置内容有两种方式：

| 方式 | 操作 |
| --- | --- |
| 菜单 / 工具栏 | **插入 → 图片 / 文本 / 表格 / 形状 / 装饰**，或用工具栏上的「图片 / 文本 / 表格」按钮 |
| 素材库 | 右侧 **素材库** 标签页 → 导入素材 → 双击素材插入图片 |

「插入工具栏」默认隐藏，需要在菜单栏的 **插入** 菜单项上**右键**，勾选
**显示插入工具栏** 才会出现。

插入后的常用操作：

- 单击选中，拖动移动
- 拖动四周 8 个手柄缩放，拖动顶部圆点旋转
- **双击**组件编辑内容：文本 → 文本样式；表格 → 编辑表格；贴纸 → 颜色 / 卡片边框
- 右键组件 → 编辑、置顶 / 置底、锁定、复制、删除

> 插入的组件默认落在画布左上角附近；图片默认尺寸 300×200、文本 300×60、表格 420×200。

## 4. 调整布局

- `Ctrl+滚轮`：以鼠标为中心缩放画布（范围 10%–800%）
- 拖动空白处：框选多个组件
- **编辑 → 对齐**：≥2 个组件时可用；**水平 / 垂直等距分布**：≥3 个时可用
- **编辑 → 网格吸附**、**对齐参考线吸附**：默认开启，网格间距 10px、吸附阈值 6px
- 右侧 **图层** 标签页：调整层序（上移 / 下移 / 置顶 / 置底）、勾选可见性
- `Ctrl+Z` / `Ctrl+Y`：撤销 / 重做（插入与删除不进撤销栈，拖动、缩放、改内容、粘贴、对齐、分布可撤销）

## 5. 导出

1. **文件 → 导出…**（`Ctrl+E`）
2. 设置：

   | 选项 | 说明 |
   | --- | --- |
   | 导出范围 | 当前页 / 当前攻略全部页 |
   | 导出格式 | 逐页 PNG / 长图（纵向拼接） |
   | 分辨率倍率 | 1x / **2x（推荐，默认）** / 3x |
   | 添加作者署名 | 需先在 **文件 → 设置** 填好作者名；可在「署名设置…」调位置 / 字体 / 颜色 / 不透明度 |
   | 导出到 | 默认填上次导出目录 |

3. 点 **导出**，完成后提示框里有 **打开目录** 按钮

导出文件名规则：`<攻略名>_01.png`、`_02.png`…；长图为 `<攻略名>_长图.png`。
导出默认倍率是 2x——平台会压缩图片，宁大勿小。
