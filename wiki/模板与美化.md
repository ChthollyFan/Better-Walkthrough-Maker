# 模板与美化

## 1. 模板是什么

模板 = **一个攻略的完整初始布局**：攻略类型（决定分类）+ 描述 + 若干页面（含页面上的组件）。

- 模板只管**布局**，外观（配色 / 装饰）由主题与贴纸负责，两者解耦
- 新建攻略时选模板 → 生成初始页面 → 之后自由编辑
- 目前所有内置模板都是**单页 1080×1440**

## 2. 内置六类模板

| 模板 | 类型标识 | 内容 |
| --- | --- | --- |
| 装备推荐 | `equipment` | 标题 + 装饰线 + 3 张装备卡片（图位、武器名、获取途径、推荐度星标） |
| 属性 / 数值对比 | `stats_compare` | 标题 + 装饰线 + 960×360 表格（属性 / 方案 A / 方案 B 示例数据）+ 使用说明文本 |
| 剧情流程 | `story_flow` | 标题 + 装饰线 + 时间线（竖线、序号圆点、四步步骤文本与描述） |
| 武器 / 角色评测 | `weapon_review` | 标题 + 装饰线 + 大图位 + 评分星标 + 优点 / 缺点列表 |
| 地图 / 点位 | `map_points` | 标题 + 装饰线 + 地图背景占位 + 3 个点位标注 |
| 通用封面 | `cover` | 攻略标题 + 副标题 / 版本说明 + 配图位 + 分割线 + 作者与更新日期 |

另有 **空白模板（1 页）**：不套用任何布局，只按全局默认画布尺寸建一页。
在「新建攻略」对话框中它固定排在最后，默认选中第一行（即第一个真实模板）。

内置模板的组件 ID 在创建攻略时由程序重新生成，因此可以不断复用。

## 3. 用户模板

用户模板保存在**当前项目**的 `templates/` 目录（第一次保存时才创建），文件为 `.json`。

| 操作 | 入口 | 说明 |
| --- | --- | --- |
| 保存为模板… | 项目树攻略节点右键 / 攻略菜单 | 把当前攻略（含全部页面）存为模板；攻略没有页面时会拒绝并提示 |
| 导出当前攻略为模板… | 攻略菜单 | 导出成可分享的 `.json`（文件名取攻略标题，非法字符替换为 `_`） |
| 导入模板… | 攻略菜单 | 从 `.json` 导入到当前项目 `templates/` |

文件名重名时会自动加 ` (2)`、` (3)` 后缀。读取失败的模板文件会被静默跳过。

「新建攻略」对话框里列出的是 **内置模板 + 当前项目的用户模板**。

模板文件格式见 [数据格式](数据格式.md)。

## 4. 贴纸装饰（素材包）

`插入 → 装饰` 提供内置的六种装饰素材，插入后即成为普通组件，可自由缩放、旋转、改颜色：

| 装饰 | 默认尺寸 | 典型用途 |
| --- | --- | --- |
| 标题装饰线 | 320×16 | 标题下方色条 |
| 角标 | 60×40 | 序号 / 角标标记 |
| 推荐度星标 | 160×28 | 装备推荐度 |
| 箭头 | 120×40 | 流程指引 |
| 分割线 | 320×12 | 分节 |
| 卡片边框 | 320×180 | 框住装备 / 地图图片，支持形状、颜色、框内图片与取景 |

卡片边框的详细用法见 [画布与组件](画布与组件.md)。

> 第一版装饰素材是**程序内置绘制**的，暂不支持导入外部素材文件。

## 5. 主题与界面外观

程序里有两个互不影响的「外观」概念：

| 概念 | 影响范围 | 入口 | 当前可选值 |
| --- | --- | --- | --- |
| **界面外观** | 窗口、控件、菜单的深色 / 浅色（玻璃拟态） | 主题菜单 → 界面外观 | 深色 / 浅色 / 跟随系统（默认） |
| **画布配色** | 页面内的主色 / 辅色 / 背景色 / 默认文字色 | 主题菜单 → 画布配色 | 目前仅「浅色页面」一种，因此该分组不显示 |

画布配色「浅色页面」的取值：

| 项 | 值 | 用在哪 |
| --- | --- | --- |
| 主色 | `rgb(29,53,87)` 深蓝 | 形状描边、贴纸默认颜色 |
| 辅色 | `rgb(69,123,157)` 蓝 | 形状填充 |
| 背景色 | 白色 | 画布底色、导出图的底色 |
| 文字色 | `rgb(33,33,33)` 近黑 | 新文本默认颜色、文章导出正文字色 |

关键规则：

- 切换画布配色**不会改写已有组件的颜色**，只影响新插入组件与画布底色
- 页面本身**不保存背景色**，渲染时由当前主题提供，因此换主题后导出图底色也会变
- 「跟随系统」会随系统深浅色变化自动刷新界面

## 6. 尚未支持

模板占位符 / 变量、模板市场 / 在线分享、素材包外部文件导入、项目级自定义主题目录等均未实现。
