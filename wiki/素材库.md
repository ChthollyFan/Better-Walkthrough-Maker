# 素材库

素材库面板位于主窗口右侧的 `素材库` 标签页（仅画布模式可见），用于管理项目内的图片素材。

## 1. 素材从哪来

素材库列出的是当前项目 `assets/` 目录下的图片文件，支持
`*.png *.jpg *.jpeg *.bmp *.webp *.gif`。

项目内没有独立的素材索引文件，素材列表就是目录扫描的结果。

素材的存储规则：

- 导入时**用 UUID 重命名**（`<uuid>.<原扩展名>`）后复制进 `assets/`
- 不保留原文件名、不做内容去重
- 源文件本来就在该项目 `assets/` 下时不会重复复制
- **没有打开项目时不会复制**，直接引用源文件路径

除素材库外，以下功能也会把外部图片复制进 `assets/`：

- 页面背景图（`从图片新建页面` / `设置背景图`）
- 卡片边框的框内图片
- 文章编辑器插入的图片、从 `.md` 导入的本地图片

## 2. 界面

- 顶部：`导入素材…` 按钮
- 下方：图标模式的素材列表，缩略图 56×56 等比缩放，列表项文本是文件名，
  鼠标悬停显示**文件绝对路径**

## 3. 操作

### 导入素材

点 `导入素材…`，可多选文件。未打开项目时会提示「请先打开项目」。

> 目前**不支持**从资源管理器拖拽图片进素材库或画布（整个程序都没有实现拖放）。

### 插入到画布

**双击**素材，或在素材上**右键 → 插入到画布**：

- 会在当前页插入一个图片组件，尺寸 300×200，插入后自动选中并滚动到该组件
- 与「插入 → 图片」不同，素材插入路径**不会检查是否已选中页面**，
  因此请先确认左侧选中了要编辑的页面

### 删除素材

右键 → `删除素材`。删除前会**全项目检查引用**，只要素材正被下列任一位置使用就拒绝删除，
并提示「该素材正被页面（组件或页面背景图）引用，无法删除」：

1. 页面背景图
2. 图片组件的图片
3. 卡片边框的框内图片

未被引用时会直接删除 `assets/` 下的文件并刷新列表。

> ⚠️ 引用检查**不包含文章 Markdown 正文中的 `![](assets/xxx.png)` 引用**。如果某张图只在
> 文章里被引用，素材面板仍会允许删除，删除后文章中的图片就会失效。

## 4. 尚未支持

素材重命名、素材排序、多选、拖拽插入、分类 / 标签、素材库统计等均未实现。
